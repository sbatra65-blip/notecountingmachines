Hand checks work when you take a few notes a day. Once cash is a big part of your business, a machine is faster, steadier and checks things your eyes can't. Here's how they compare, with honest limits on both sides.

## Speed: 100 notes

| Method | Time for 100 notes | Fake check included? |
|---|---|---|
| Hand count only | about 1–2 minutes* | No |
| Hand count + 5 security checks per note | about 15–20 minutes* | Visible features only |
| Kores EasyCount 442 (900 notes/min) | about 7 seconds | UV, MG, IR on every note |
| T-100 / T-800 (1,200 notes/min) | about 5 seconds | UV, MG, IR, MT on every note |
| T-800 with mixed notes | about 5 seconds, **total ₹ shown** | Same, plus no sorting by denomination |

*Our working estimates for a practised cashier; time your own staff. The five hand checks (tilt, light, latent image, micro letters, touch) take about 10 seconds a note.

## Accuracy: what each method actually checks

| Check | By hand | Machine (UV/MG/IR/MT) | Note sorter (CIS) |
|---|---|---|---|
| Count | Errors creep in when tired or rushed | Accurate; stops on double, half and chain notes | Accurate |
| UV (paper and ink glow) | Only with a UV torch | Yes | Yes |
| MG (magnetic ink) | Cannot | Yes | Yes |
| IR (infrared print) | Cannot | Yes | Yes |
| Security thread | Look and tilt | MT sensor | Yes |
| Colour-shift ink | Tilt, yes | Most counters don't | Full image scan |
| Raised print | Feel, yes | No | No |
| Watermark, see-through register | Hold to light, yes | No | Full image scan |
| Same on note 1 and note 1,000 | No, attention drops | Yes | Yes |

The two methods catch different things, which is why they work best together: **the machine checks every note, and a person checks the few it rejects.** RBI's rules for banks work the same way: notes paid in at the counter are examined by machine, and every note of ₹100 and above must be machine-checked before it goes back out.

## Honest limits of machines

- **No machine is 100%.** A UV-only counter misses fakes printed on paper that doesn't glow. Choose at least UV + MG + IR.
- **Worn or dirty genuine notes** can be rejected. Check those by hand.
- **New note series** need a software update. We do this free for our customers.
- Most counters don't read colour-shift ink or raised print. Only CIS sorters scan the full image.

## Cost: when does a machine pay for itself?

- **One fake ₹500 = ₹500 lost.** The Kores EasyCount 442 at ₹13,750 costs the same as 27–28 fake ₹500 notes.
- **Staff time:** hand-checking 500 notes a day at 10 seconds each is about **83 minutes a day**. A machine does it in under a minute.
- **Mixed cash:** a mix value counter like the T-800 also removes the sorting and adding up, and the arithmetic mistakes.
