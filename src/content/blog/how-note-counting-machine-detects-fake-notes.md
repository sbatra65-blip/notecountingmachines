A note counting machine with fake note detection runs every note past several sensors while it counts. Each sensor checks one feature of a genuine note, and the machine stops and alerts you when a note fails.

## The five sensors

| Sensor | What it checks | Catches |
|---|---|---|
| UV (ultraviolet) | Paper and fluorescent ink | Fakes on ordinary paper, which glows under UV |
| MG (magnetic) | Magnetic ink in set areas of the note | Notes printed without magnetic ink |
| IR (infrared) | Inks that look different in infrared light | Colour-copied and inkjet fakes |
| MT (magnetic thread) | The security thread | Notes with a printed or missing thread |
| CIS (contact image sensor) | A full image of the note | Most fakes, and reads the denomination |

## What each sensor can miss

UV and MG alone can be passed by good-quality "super fakes" that use better paper and some magnetic ink. That is why three or more independent checks matter: a fake has to beat all of them at once.

CIS machines are the most thorough because they compare an image of the whole note. The same image lets them recognise the denomination, which is how **mix value counters** total a stack of mixed ₹10 to ₹500 notes.

## Which sensor set do you need?

- **Small shop, office, restaurant:** UV, MG and IR, such as the Kores EasyCount 442.
- **Petrol pump, supermarket, high cash volume:** add MT, such as the T-100.
- **Jeweller, wholesaler, mixed cash all day:** a mix value counter with UV, MG, IR and MT, such as the T-800.
- **Bank branch:** CIS value counters and note sorters.
