Fake ₹500 notes were about 62% of all counterfeits found in India in 2025-26, so this is the note worth learning first. These five checks take about ten seconds and need no equipment.

## 1. Tilt it: colour-shifting thread

The windowed security thread, with the words भारत and RBI, changes from **green to blue** when you tilt the note. On most fakes the thread is printed, so it stays one colour.

## 2. Tilt again: the ₹500 numeral at bottom right

The numeral with the rupee symbol at the bottom right is printed in colour-changing ink. It also moves from **green to blue**.

## 3. Hold it to the light: watermark and see-through register

Against light you should see the **Mahatma Gandhi portrait and an electrotype 500 watermark** in the blank area. The small floral **see-through register** with the numeral 500 lines up perfectly from front and back.

## 4. Hold it flat at eye level: latent image

Hold the note horizontally at eye level. A **latent 500** appears in the vertical band to the right of the portrait.

## 5. Feel it: raised print

Run a finger over the portrait, the Ashoka Pillar emblem and the **five angular bleed lines** on each edge. Genuine notes use raised (intaglio) printing that you can feel; many fakes are flat.

## When to use a machine instead

Manual checks work for a few notes. If you handle bundles, a note counting machine with UV, MG and IR sensors checks every note while counting. Read [how note counting machines detect fake notes](/blog/how-note-counting-machine-detects-fake-notes/).
